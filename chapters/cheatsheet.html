Appendix BCommand cheat sheet

Every SwarmPipe command, scenario, runtime flag and dashboard tab on one page.

Complete command reference

Generated from SwarmPipe's CLI itself, so it is always accurate. sp means python -m swarmpipe (see Chapter 0). Add --help to any command for details.

(top level)

Command Arguments and options What it does
sp ask <question> --as <v> --tenant <v> Ask the Analyst agent a natural-language question over published data.
sp evidence <incident_id> --html/--no-html Export the evidence pack of an incident (JSON + HTML).
sp init   Create data folders, the state DB, import contracts, seed knowledge, register agents, lock prompts.
sp killswitch <state> --scope <v> --reason <v> --as <v> Engage/release a kill switch. Scopes: global, agent:, tenant:, action:, llm.
sp maintenance <task>  
sp mcp --as <v> Run the MCP server over stdio (for GitHub Copilot CLI, Claude Desktop, VS Code, ...).
sp metrics --prom/--no-prom Metric summaries (or Prometheus exposition with --prom).
sp policy <action> --dataset <v> --tenant <v> --confidence <v> --blast <v> --injection/--no-injection --regulated/--no-regulated Simulate the policy engine for a hypothetical action (what-if).
sp reset --yes Move the data folder to data/../.trash- (recoverable) and start fresh.
sp run --port <v> --no-web/--no-no-web --workers <v> --profile <v> Start the watcher, workers, event dispatcher, scheduler and the web dashboard.
sp slo   SLOs of the pipeline itself: SLI, error-budget burn.
sp status   Overview: runs, incidents, approvals, datasets, cost, kill switches.
sp tick --timeout <v> --scheduler/--no-scheduler Process everything synchronously (no server): watcher poll -> runs -> events -> monitors, until quiet.
sp trace <ident> Show a trace waterfall for a run id, incident id or trace id.

actions

Command Arguments and options What it does
sp actions execute <proposal_id> --as <v> Execute an L1 recommendation yourself (attributed to you; counts as agreement evidence).
sp actions rollback <proposal_id> --as <v> Compensate an executed action (the L3 'act and notify' one-click rollback).

chaos

Command Arguments and options What it does
sp chaos advance-clock <minutes> Fast-forward the business clock (freshness SLAs).
sp chaos clear    
sp chaos crash-after --step <v> The worker process exits right after checkpointing STEP of the next run (restart swarmpipe run to see recovery).
sp chaos set <key> <value> e.g. chaos set llm_timeout_rate 0.3, chaos set guardrails.spotlighting false, chaos set feature.critic_review false.
sp chaos show    
sp chaos tamper-warehouse --dataset <v> --tenant <v> Modify a published table directly (the out-of-band detector should catch it).

dlq

Command Arguments and options What it does
sp dlq list    
sp dlq redrive <dlq_id> Move a dead-lettered file back into the inbox (after fixing the cause).

evals

Command Arguments and options What it does
sp evals calibrate-judge --version <v> Measure LLM-as-judge agreement with human labels (kappa) plus position and verbosity bias.
sp evals certify --model <v> --roles <v> Run the eval suites with MODEL for each role and record whether it is certified for that role.
sp evals gate --update-lock/--no-update-lock --k <v> CI gate: run the suites and fail (exit 1) if any threshold is missed.
sp evals harvest   Turn reviewed production incidents into candidate regression cases (feedback -> eval flywheel).
sp evals run --suite <v> --k <v> --noise <v> --profile <v> --cases <v>

Scenarios

Use with sp scenarios drop <name> (add --process to run it synchronously without a server).

Scenario What it simulates
reference customers.xlsx (2 sheets -> customers + regions) and inventory .xls
history 4 clean days of sales (builds volume and distribution baselines)
baseline reference + history (run this first)
clean_day today's normal sales file
duplicate byte-identical re-delivery of today's file
schema_drift upstream renamed customer_id->client_code, amount->net_amount
additive_drift a new promo_code column appears
volume_drop truncated extract (18 rows instead of ~500)
volume_spike 5x rows (cumulative / duplicate delivery)
unit_change amounts sent in paise (x100)
stale_resend today's file contains 30-day-old orders
quality_failure 30% invalid channel / missing quantity
referential_break 40% of customer_ids do not exist
pii_leak card numbers typed into customers.notes
injection truncated file + a cell with a prompt injection
injection_filename instructions hidden in the file name
malformed binary garbage .csv and a fake .xlsx
encoding cp1252-encoded customers CSV
pipe_txt pipe-delimited inventory .txt
new_dataset unknown vendors_q3.csv
runbook_doc a free-text runbook
poisoned_doc a document with injected instructions
mass_failure 6 files with the same schema drift
freshness fast-forward the business clock 26h
oob_tamper modify the published sales table directly
crash crash the worker after 'transform' on the next file
llm_outage sim-large down + a volume drop
flaky_llm 25% timeouts + 30% malformed JSON + a unit change
