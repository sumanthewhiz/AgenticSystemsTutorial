How this tutorial works

Every chapter teaches one set of production concepts in four moves:

You'll need about 20 minutes of setup (Chapter 0). After that, everything runs locally and offline, with no API keys and no cloud account. SwarmPipe's simulated models make every failure reproducible, and you can switch to a real local model whenever you like.
